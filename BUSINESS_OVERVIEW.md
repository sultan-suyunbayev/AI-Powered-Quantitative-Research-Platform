# QuantAI Platform — Бизнес-обзор

> **Canonical Reference**: [Design_Doc_CCEA_Cloud.txt](docs/design/CCEA_CLOUD/Design_Doc_CCEA_Cloud.txt)

## Краткое описание

**QuantAI** — платформа алгоритмической торговли на основе искусственного интеллекта с архитектурой **CCEA** (Cloud-Controlled Execution Architecture), разработанная для производственного использования. Объединяет машинное обучение (reinforcement learning) с симуляцией исполнения институционального уровня для систематической торговли на 5 классах активов.

**Статус**: Продукт разработан для выхода на рынок (Designed for Production)
**Архитектура**: CCEA Cloud v3.0 (Cloud research/monitoring + Agent execution)

---

## Проблема рынка

### Текущая ситуация

1. **Фрагментация инфраструктуры**
   - Создание торговой инфраструктуры требует 6-12 месяцев и €200K-500K
   - Каждый класс активов = отдельная команда и кодовая база
   - 3-5x накладные расходы на инженерию

2. **Разрыв между тестами и реальностью**
   - Отклонение бэктестов от реальной торговли: 20-40% (среднее по индустрии)
   - Потери от неточного моделирования исполнения: 15-30 bps ежегодно

3. **Регуляторное бремя**
   - MiFID II, EU AI Act, DORA требуют отдельной имплементации
   - 6-12 месяцев на сертификацию для каждого регулятора

4. **Операционные риски**
   - $2.3 млрд потерь от операционных сбоев в 2023 году (Risk.net)
   - Ручные процессы = высокий риск ошибок

## Возможности платформы

### 1. Искусственный интеллект для торговли

**Distributional PPO с Twin Critics** — собственная архитектура RL:
- Фокус на управлении рисками (CVaR — условный VaR)
- Устойчивость к смене рыночных режимов
- Автоматическая адаптация к новым условиям
- Непрерывное обучение без "забывания" предыдущих режимов

**Уникальные инновации:**
- Population-Based Training — эволюционная оптимизация гиперпараметров
- Adversarial Training — защита от экстремальных сценариев
- Conformal Prediction — квантификация неопределенности без предположений о распределении

### 2. Симуляция исполнения

Три уровня точности:
- **L1**: Базовые фиксированные спреды
- **L2+**: 6-9 факторная TCA модель (production default)
- **L3**: Полная симуляция книги заявок

**Факторы модели L2+:**
- Рыночная капитализация и ликвидность
- Время суток (168-часовые паттерны)
- Волатильность режима
- Дисбаланс книги заявок
- Стресс funding rate (крипто)
- Circuit breakers (CME)

**Академическая база:**
- Almgren-Chriss (2001) — рыночное воздействие
- Kyle (1985) — ценовое воздействие
- Gatheral (2010) — затухание воздействия
- Moallemi & Yuan (2017) — оптимизация лимитных ордеров

### 3. Риск-менеджмент

Многоуровневая защита:
- Лимиты позиций (по символу и портфелю)
- Мониторинг маржи в реальном времени
- Kill Switch для экстренной остановки
- Границы неопределенности (conformal prediction)
- Контроль просадки
- No-trade окна (календарные запреты)
- PDT правила (для US акций)

### 4. Регуляторный комплаенс

| Регулятор | Статус | Охват |
|-----------|--------|-------|
| **MiFID II** | Готово к соответствию | 7/7 фаз, 200+ тестов |
| **EU AI Act** | Готово к соответствию | 4/4 фаз, 1,007 тестов |
| **DORA** | Готово к соответствию | 5/5 фаз, ~1,015 тестов |

**Готовые документы:**

- GPAI Model Card

### 5. CCEA Архитектура (Cloud-Controlled Execution Architecture)

Уникальная архитектура, обеспечивающая безопасность и регуляторный комплаенс:

| Компонент | Ответственность | Доступ к секретам | Исполнение ордеров |
|-----------|-----------------|-------------------|-------------------|
| **Cloud** | Research, backtest, мониторинг, lifecycle | **НИКОГДА** | **НИКОГДА** |
| **Agent** | Live execution, risk, vault, broker | **Только локально** | **ДА** |

**Ключевые гарантии безопасности:**
- Cloud **НИКОГДА** не хранит API ключи брокеров
- Cloud **НИКОГДА** не генерирует, не передаёт и не исполняет торговые ордера
- Все торговые операции происходят **ТОЛЬКО** в Agent на стороне клиента
- Телеметрия **ВСЕГДА** редактируется перед передачей в Cloud

**Режимы продукта:**
1. **Retail Research SaaS**: Cloud исследования + опциональный BYO Agent
2. **Retail Live via Agent**: Локальное исполнение, облачный мониторинг
3. **Enterprise On-Prem**: Полный стек в инфраструктуре клиента

**Правовая позиция:**
- **НЕ** инвестиционный советник и не брокер
- **НЕ** кастодиан активов или учётных данных
- Поставщик ПО для независимых трейдеров

- **6-12 месяцев экономии** на сертификации

### 3. Собственные инновации (IP)

- Distributional PPO + CVaR — risk-aware RL
- AdaptiveUPGD — continual learning без катастрофического забывания
- Variance Gradient Scaler v3.2 — стабильность обучения
- Twin Critics — уменьшение переоценки

### 4. Готовность к Production

- 14,000+ автоматизированных тестов
- 97%+ pass rate
- Протестировано с live trading на 4+ биржах
- 340,000+ строк кода
