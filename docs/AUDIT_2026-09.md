# Repository audit — September 2026

Scope: the full tracked tree at `main@d1f5881` — 1 785 commits, 3 454 tracked files, ~50 MB
on GitHub. Purpose: prepare the repository for a public Apache-2.0 release (v1.0.0).

Severity: **P0** blocks the release · **P1** should be fixed before it · **P2** cosmetic.
Status is what actually happened on the `cleanup/public-release` branch.

The short version: nothing was leaking secrets, and the code is real. What was broken was
everything around it — the licence said proprietary, the dependency locks could not be
installed, so CI had been red for months and every quality tool in it was failing to run
rather than passing. Once they ran, they found things.
