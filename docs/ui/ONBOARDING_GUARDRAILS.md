# UI/Onboarding Guardrails

> **Version**: 1.0.0 | **Last Updated**: 2025-12-16

## Overview

This document defines the required disclaimers, warnings, and acknowledgment flows for the Platform's user interface. These guardrails are designed to support compliance efforts and set proper user expectations.

---

## Mandatory Disclaimers

### D1: Not Investment Advice

**Display Location:** Footer, About page, Strategy creation

**Text:**
```
The Platform provides software tools for quantitative research and deployment.
It does NOT provide investment advice, portfolio management, or trade recommendations.
All trading decisions are yours.
```

**Format:** Persistent footer link + full text on legal pages

### D2: Risk Warning

**Display Location:** Registration, Live execution activation

**Text:**
```
⚠️ RISK WARNING

Trading involves substantial risk of loss. You may lose more
than your initial investment. Only trade with money you can
afford to lose. Past performance does not guarantee future results.
```

**Format:** Modal/banner, requires acknowledgment before proceeding

### D3: AI-Generated Content

**Display Location:** All AI outputs (research outputs, predictions, reports)

**Text:**
```
[AI-GENERATED]
This content was generated by an AI system. AI predictions may
be inaccurate. You are responsible for all trading decisions.
```

**Format:** Inline prefix + info tooltip

### D4: CCEA Architecture Notice

**Display Location:** Agent setup, Credential entry

**Text:**
```
🔒 YOUR CREDENTIALS STAY LOCAL

Under CCEA architecture, your broker API keys are designed to be stored
on YOUR hardware in an encrypted vault. The Cloud is designed not to
receive or store your trading credentials (enforced via CCEA architecture).
```

**Format:** Info card during Agent setup

## Acknowledgment Flows

### A1: Registration Acknowledgment

**Trigger:** Account creation

**Required Acknowledgments:**
1. ☐ I have read and agree to the Terms of Service
2. ☐ I have read and agree to the Privacy Policy
3. ☐ I understand this platform provides software tools, not investment advice
4. ☐ I am at least 18 years old

**Implementation:**
```html
<form id="registration-acknowledgments">
  <label>
    <input type="checkbox" name="tos" required>
    I have read and agree to the <a href="/legal/tos">Terms of Service</a>
  </label>
  <label>
    <input type="checkbox" name="privacy" required>
    I have read and agree to the <a href="/legal/privacy">Privacy Policy</a>
  </label>
  <label>
    <input type="checkbox" name="not-advice" required>
    I understand this platform provides software tools, not investment advice
  </label>
  <label>
    <input type="checkbox" name="age" required>
    I am at least 18 years old
  </label>
  <button type="submit" disabled>Create Account</button>
</form>
```

**Required Acknowledgments:**

3. ☐ I have sufficient knowledge and experience to trade

      I understand I may lose more than my initial investment
    </label>
    <label>
      <input type="checkbox" name="knowledge" required>
      I have sufficient knowledge and experience to trade
    </label>
    <label>
      <input type="checkbox" name="responsibility" required>
      I am solely responsible for all trading decisions
    </label>
    <label>
      <input type="checkbox" name="ai-limitations" required>
      I understand AI-generated outputs may be inaccurate
    </label>
    <label>
      <input type="checkbox" name="risk-limits" required>
      I will maintain appropriate risk limits
    </label>

**Storage:** Record acknowledgment timestamp, IP, user agent for audit trail

**Trigger:** Deploying strategy for live execution (via Agent)

**Required Acknowledgments:**

## Warning Banners

### W1: Paper Trading Mode

**Display:** Always visible when in paper trading

**Text:**
```
📝 PAPER TRADING MODE - No real orders are executed
```

**Style:** Blue info banner, non-dismissible

### W2: Live Execution Mode

**Display:** Always visible when live execution is active

**Text:**
```
🔴 LIVE EXECUTION ACTIVE - Real orders are being executed (via your Agent)
```

**Style:** Red warning banner, non-dismissible

### W3: Kill Switch Active

**Display:** When trading is halted

**Text:**
```
⛔ EXECUTION HALTED - Kill switch activated
Reason: {reason}
All orders cancelled. Positions held.
[View Details] [Acknowledge]
```

**Style:** Critical red modal, requires acknowledgment

### W4: Degraded Mode

**Display:** When operating in degraded mode

**Text:**
```
⚠️ DEGRADED MODE: {mode_name}
{description}
Automatic recovery in progress...
```

**Style:** Orange warning banner

### W5: Approval Required

**Display:** When local approval is pending

**Text:**
```
🔐 APPROVAL REQUIRED
{action_description}
This action requires your local approval.
[Approve] [Reject] [View Details]
```

**Style:** Yellow attention modal

## Toast Notifications

### T1: Order Executed

**Trigger:** Order fills

**Content:**
```
✅ Order Executed
{symbol} {side} {quantity} @ {price}
[View Details]
```

**Duration:** 5 seconds, dismissible

### T2: Approval Required

**Trigger:** Pending approval

**Content:**
```
🔐 Approval Required
{action} needs your approval
[Review Now]
```

**Duration:** Until dismissed or approved

### T3: Kill Switch Triggered

**Trigger:** Kill switch activation

**Content:**
```
⛔ TRADING HALTED
Kill switch triggered: {reason}
[View Details]
```

**Duration:** Until acknowledged

### T4: Connection Lost

**Trigger:** Cloud disconnection

**Content:**
```
⚠️ Cloud Connection Lost
Agent operating in degraded mode
[Retry Connection]
```

**Duration:** Until connection restored

## Compliance Checklist

### Pre-Launch UI Audit

- [ ] All mandatory disclaimers are displayed
- [ ] Registration requires ToS/Privacy acknowledgment
- [ ] Live execution activation requires risk acknowledgment
- [ ] AI content is marked with [AI-GENERATED]
- [ ] Paper vs Live execution is clearly distinguished
- [ ] Kill switch status is visible when active
- [ ] Risk controls are visible and editable
- [ ] CCEA architecture is explained during Agent setup
- [ ] Approval flows work correctly
- [ ] All acknowledgments are logged for audit

### Accessibility Requirements

- [ ] Disclaimers are screen-reader compatible
- [ ] Color is not the only indicator (icons + text)
- [ ] Modal dialogs are keyboard navigable
- [ ] Contrast ratios meet WCAG 2.1 AA
- [ ] Focus management works correctly

### Localization Requirements

- [ ] Disclaimers available in required languages
- [ ] Risk warnings translated accurately
- [ ] Legal links point to localized versions
- [ ] Date/number formats localized

## API Headers

### AI Content Headers

All AI-generated API responses must include:

```http
X-AI-System: true
X-AI-Model: distributional-ppo-v1
X-AI-Disclaimer: AI-generated content may be inaccurate
```

### Architecture Headers

All responses include:

```http
X-CCEA-Zone: cloud
X-CCEA-Version: 1.0.0
```

Agent responses include:

```http
X-CCEA-Zone: agent
X-CCEA-Agent-ID: agent_xyz
```
